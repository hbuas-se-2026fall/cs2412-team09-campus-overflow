- 学生登录后进入问题列表页，按课程筛选、按标签筛选
- 点击"提问"按钮，填写标题/正文/标签，提交后出现在列表顶部
- 空状态、加载状态、错误状态均有友好提示

**PO 验收结果**：US-01 ✅ 通过、US-02 ✅ 通过

**反馈**：

- 列表分页暂时用滚动加载，后续再优化
