## Sprint Review

**演示内容**：
- 搜索"Maven 依赖"，返回标题/正文包含该词的问题，按相关度排序
- 问题详情页侧边栏显示 5 条相似问题
- 评论里输入 @张三，提交后张三收到通知
- 提问者发起 50 分悬赏，采纳后回答者自动到账 50 分
- 个人主页显示声誉总分和获得的徽章，排行榜页高亮自己的位置
- 顶部铃铛显示未读角标，点击进入通知中心，标记已读

**PO 验收结果**：US-07 ✅、US-08 ✅、US-09 ✅、US-10 ✅、US-11 ✅

**反馈**：
- 搜索中文分词效果一般，"软工"匹配不到"软件工程"（记录为已知限制）
- 通知中心需要支持"全部已读"按钮（已补）
